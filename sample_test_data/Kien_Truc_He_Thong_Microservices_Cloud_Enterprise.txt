NGÀY PHÁT HÀNH: 2026 - TÀI LIỆU LƯU HÀNH NỘI BỘ

1. TỔNG QUAN KIẾN TRÚC (ARCHITECTURE OVERVIEW):
- Hệ thống áp dụng kiến trúc phân tán Microservices hướng sự kiện (Event-Driven Microservices), chạy trên cụm Kubernetes (EKS / GKE) đa vùng khả dụng (Multi-AZ).
- Tách bạch hoàn toàn giữa tầng Giao diện (Next.js 14 App Router), Tầng Dịch vụ Nghiệp vụ (Spring Boot 3.x REST/GraphQL API) và Tầng Trí tuệ Nhân tạo (FastAPI Python AI Microservice).

2. CÁC THÀNH PHẦN CỐT LÕI (CORE COMPONENTS):
- API Gateway & Authentication:
  + NGINX / Spring Cloud Gateway xử lý Rate Limiting, SSL Termination, Reverse Proxy.
  + Keycloak / Spring Security tích hợp JWT token, hỗ trợ SSO LDAP/Active Directory của doanh nghiệp.
- Data & Storage Layer:
  + PostgreSQL 16: Lưu trữ dữ liệu quan hệ, cây thư mục phân cấp, phân quyền ACL, lịch sử kiểm toán audit log.
  + pgvector / Qdrant: Vector Database lưu trữ Embedding 1536 chiều của toàn bộ tài liệu doanh nghiệp.
  + MinIO / AWS S3: Lưu trữ Object Storage cho file gốc (PDF, DOCX, XLSX, TXT) với mã hóa Server-side Encryption (SSE-S3).
  + Redis 7: Bộ nhớ đệm phân tán cho Session, kết quả tìm kiếm và Cache quyền hạn người dùng.

3. LUỒNG XỬ LÝ DỮ LIỆU RAG & GENERATIVE SLIDE:
- Bước 1 (Ingestion & Chunking): Tài liệu tải lên được giải mã văn bản, cắt đoạn thông minh theo ngữ nghĩa (Semantic Chunking, 500-1000 tokens/chunk, overlap 15%).
- Bước 2 (Vector Embedding): Sử dụng mô hình text-embedding-004 tạo vector biểu diễn ngữ nghĩa.
- Bước 3 (Hybrid Search): Kết hợp Keyword Search (BM25) và Vector Search (Cosine Similarity) để đạt độ chính xác Recall > 92%.
- Bước 4 (TypeSafe Gemini PPTX Generation): Sử dụng Gemini TypeSafe JSON Schema định nghĩa cấu trúc Slide bài thuyết trình (Tiêu đề, Luận điểm, Số liệu KPI, Callout). Client Next.js dựng bản trình chiếu PowerPoint 16:9 chất lượng cao qua thư viện pptxgenjs.

4. BẢO MẬT & ĐỘ TIN CẬY (SECURITY & RELIABILITY):
- Phân quyền theo nguyên tắc đặc quyền tối thiểu (Least Privilege) và kế thừa động từ thư mục cha.
- Mã hóa dữ liệu truyền tải (Data in Transit) chuẩn TLS 1.3 và dữ liệu lưu trữ (Data at Rest) chuẩn AES-256.
- Cam kết độ sẵn sàng SLA 99.95%, thời gian phục hồi thảm họa RPO < 15 phút, RTO < 30 phút.
